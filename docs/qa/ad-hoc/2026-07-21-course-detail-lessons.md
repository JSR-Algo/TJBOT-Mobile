## Problem

`CourseDetailScreen` showed a lesson *count* but never a lesson *list*, and
resolved every backend-UUID course to the hardcoded `COURSES[2]` ("Yummy
Words"), printing an unrelated course's blurb / teaches / ages / pace under the
real course title.

Observed on a physical device (Redmi Note 12, `2312DRA50C`, Android 16) against
prod backend `tbot-backend-8wmh.onrender.com/v1`: course **Barn Farm Place
Words** rendered "Mealtime English — fruits, snacks, and gentle table phrases.",
"Food / Asking politely / Likes & dislikes / Numbers 10–20", "Ages 5–7 ·
Building up", "7w" — all belonging to `c_food`.

## Critique-before-close

1. **Root cause vs symptom** — root cause. The screen never called the lessons
   endpoint (`getCourseLessons` existed but only `SendToRobotScreen` used it),
   and `?? COURSE` guaranteed a content mismatch for every authored course.
2. **Code vs docs** — no contract change; both endpoints are already documented
   in `course-library.api.ts` (`GET /courses`, `GET /courses/:id/lessons`).
3. **Test quality** — behavioral, not ceremonial: AC2's test fails against the
   old code (it asserted "Yummy Words" is absent, which the old fallback
   guaranteed present).
4. **Drift** — none introduced. Pre-existing drift noted: `.agent/*` still uses
   `TJBot/TJBot-mobile` paths for a repo now at `TBOT/tbot-mobile`.
5. **PE cold review** — a principal would ask about the count/list mismatch
   below; it is surfaced, not hidden.
6. **Reproducibility** — commands above are deterministic; the device walk is
   Library tab → course card.

## Original note (NOT fixed at the time — backend data, out of sys-16 scope)

The stat grid reads **6 Bài học** while the list renders **1**. The count comes
from `GET /courses` (`lesson_count: 6`); the list comes from
`GET /courses/{id}/lessons`, which returns a single published lesson. Either 5
lessons are authored-but-unpublished, or the two endpoints disagree. Owner:
tbot-backend. The UI now shows both numbers honestly instead of hiding the
list, which is what made the discrepancy visible at all.
