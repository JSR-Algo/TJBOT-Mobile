# Architecture

Production navigation for `tbot-mobile` lives under `src/navigation`.

## Navigation

- `src/navigation/AppNavigator.tsx` owns the `NavigationContainer`.
- `src/navigation/RootStackNavigator.tsx` gates auth, onboarding, and protected branches.
- `src/navigation/featureRegistry.ts` exports `FEATURE_NAVIGATION_REGISTRY`.
- `src/navigation/routeMap.ts` exports `ROUTE_MAP`.
- `src/navigation/routeMap.ts` exports `NAVIGATION_TREE`.

## Artifacts

- `navigation-audit.md` records the current production navigation review.
- `route-mapping.json` is generated by `npm run navigation:route-map`.
- `navigation-tree.mmd` is generated by `npm run navigation:tree`.
- `navigation-forward-edges.json` is generated by `npm run navigation:forward-edges`.

## Invariants

Route names come from `src/navigation/routes.ts`.
Feature screens register in exactly one owning `navigation.ts`.
Deep links, route ownership, and generated artifacts derive from the same feature route registry.
