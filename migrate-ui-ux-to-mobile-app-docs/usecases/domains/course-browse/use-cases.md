## UC-C01 — Browse Course Tree

- **Goal:** Child sees the available courses as the entry point to the learning tree.
- **Trigger:** Cross-domain handoff from kid-hub (UC-H04) lands the child on `course` (`CourseScreen.jsx`).
- **Preconditions:** Child has a current course assigned in `useCourseStore.currentCourseId` (or default course is rendered).
- **Main Flow:**
  1. `CourseScreen` renders the course-overview surface with a list of levels (`CourseScreen.jsx`).
  2. Each level row renders enabled or disabled per its `state` (locked rows are disabled buttons in `CourseScreen.jsx`).
  3. Child taps an unlocked level → `go('level')` fires → UC-C02 View Level.
- **Postconditions:** Navigation lands on `level`; `useCourseStore.currentLevel` has been (or will be) set by the level surface.
- **Alt Flow:**
  1. Child taps the home icon in TopBar → cross-domain handoff to home (see cross-domain-edges.json: UC-C01→UC-H01).

## UC-C02 — View Level

- **Goal:** Child sees the units inside a level and picks one to study.
- **Trigger:** UC-C01 child tapped an unlocked level row.
- **Preconditions:** `useCourseStore.currentLevel` set; level data loaded.
- **Main Flow:**
  1. `LevelScreen` renders the level-overview surface with a unit list (`LevelScreen.jsx`).
  2. Each unit row renders enabled or disabled per its `state` (`LevelScreen.jsx`).
  3. Child taps an unlocked unit → `go('unit')` fires → UC-C03 View Unit.
- **Postconditions:** Navigation lands on `unit`; `useCourseStore.currentUnit` set by the unit surface.
- **Alt Flow:**
  1. Child taps back → `go('course')` returns to UC-C01.

## UC-C03 — View Unit

- **Goal:** Child sees the lessons inside a unit plus the unit-level review affordance.
- **Trigger:** UC-C02 child tapped an unlocked unit row.
- **Preconditions:** `useCourseStore.currentUnit` set.
- **Main Flow:**
  1. `UnitScreen` renders the unit-overview surface with a lesson list and a Review button (`UnitScreen.jsx`).
  2. Each lesson row renders enabled or disabled per its `state` (`UnitScreen.jsx`).
  3. Child taps an unlocked lesson → `go('lesson_detail')` fires → UC-C05 View Lesson Detail.
- **Postconditions:** Navigation lands on `lesson_detail`.
- **Alt Flow:**
  1. Child taps "Start Review" → `go('review_entry')` → UC-C07 Start Review.
  2. Child taps "View Lesson List" affordance → UC-C04 View Lesson List.
  3. Child taps back → `go('level')` returns to UC-C02.

## UC-C04 — View Lesson List

- **Goal:** Child sees the lessons of a unit in a flat list view (alternative dense layout to UC-C03).
- **Trigger:** Child enters via the "lesson list" affordance from a unit context.
- **Preconditions:** `useCourseStore.currentUnit` set; lesson list data loaded.
- **Main Flow:**
  1. `LessonListScreen` renders the lesson list (`LessonListScreen.jsx`).
  2. Each lesson row renders enabled or disabled per its lock state (`LessonListScreen.jsx`).
  3. Child taps an unlocked lesson → `go('lesson_detail')` fires → UC-C05.
- **Postconditions:** Navigation lands on `lesson_detail`.
- **Alt Flow:**
  1. Child taps back → `go('unit')` returns to UC-C03.

## UC-C05 — View Lesson Detail

- **Goal:** Child sees what a single lesson covers before committing to start it.
- **Trigger:** UC-C03 or UC-C04 child tapped an unlocked lesson row.
- **Preconditions:** Lesson data loaded.
- **Main Flow:**
  1. `LessonDetailScreen` renders the lesson detail surface with a "Start Lesson" CTA (`LessonDetailScreen.jsx`).
  2. Child taps "Start Lesson" → `go('lesson_ready')` fires → UC-C06 Start Lesson From Detail.
- **Postconditions:** Navigation lands on `lesson_ready`.
- **Alt Flow:**
  1. Child taps back → `go('unit')` returns to UC-C03.

## UC-C06 — Start Lesson From Detail → `lesson_ready`

- **Goal:** Child commits to starting a specific lesson and is handed to the lesson-session domain.
- **Trigger:** UC-C05 child tapped "Start Lesson".
- **Preconditions:** Lesson is unlocked (client-side gate per `course-browse.usecase.puml:40` — server-side enforcement NOT CONFIRMED, KD11).
- **Main Flow:**
  1. Client transitions navigation to `lesson_ready`.
  2. Cross-domain handoff to lesson-session UC-L01 Start Voice Session (see cross-domain-edges.json: UC-C06→UC-L01).
- **Postconditions:** Navigation lands on `lesson_ready`. Lesson session has not yet started — `useLessonStore.sessionId` still null until UC-L01 fires.

## UC-C07 — Start Review

- **Goal:** Child enters the review queue for the current unit (or for items surfaced by daily review).
- **Trigger:** Child taps "Start Review" from a unit (UC-C03 alt) OR cross-domain entry from kid-hub Review button (UC-H05).
- **Preconditions:** Review queue has at least one item (else surface shows empty-state).
- **Main Flow:**
  1. `ReviewEntryScreen` renders the review surface with a "Start Review" CTA (`ReviewEntryScreen.jsx`).
  2. Child taps "Start Review" → `go('lesson_ready')` fires → cross-domain handoff to lesson-session UC-L01 (see cross-domain-edges.json: UC-C07→UC-L01).
- **Postconditions:** Navigation lands on `lesson_ready`; lesson session not yet started.
- **Alt Flow:**
  1. Child taps back → cross-domain handoff to home (see cross-domain-edges.json: UC-C07→UC-H01).

## UC-C08 — Start Daily Mission

- **Goal:** Child enters the daily-mission flow, which is a curated sequence outside the static course tree.
- **Trigger:** Cross-domain entry from kid-hub state `daily_available` (per `course-browse.usecase.puml:36`).
- **Preconditions:** Daily mission available in `useCourseStore` (NOT CONFIRMED IN SOURCE — TBD via `course.api.js → getDailyMission`).
- **Main Flow:**
  1. `DailyMissionScreen` renders the daily-mission surface with a "Continue Mission" CTA (`DailyMissionScreen.jsx`).
  2. Child taps "Continue Mission" → `go('lesson_ready')` fires → cross-domain handoff to lesson-session UC-L01 (see cross-domain-edges.json: UC-C08→UC-L01).
- **Postconditions:** Navigation lands on `lesson_ready`; lesson session not yet started.
- **Alt Flow:**
  1. Child taps back → cross-domain handoff to home (see cross-domain-edges.json: UC-C08→UC-H01).
