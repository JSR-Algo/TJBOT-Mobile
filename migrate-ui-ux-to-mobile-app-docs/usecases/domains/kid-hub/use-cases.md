## UC-H01 — View Home Hub

- **Goal:** Child sees today's rotjtjbot status and the primary daily CTA on app home.
- **Trigger:** Authenticated child lands on `home_hub_*` after login (UC-A03 success path) OR returns home from any lesson/course/progress sub-flow.
- **Preconditions:** Auth status `authenticated`; child profile present in `useAuthStore.child`.
- **Main Flow:**
  1. App reads home variant tweak (`HomeHubScreen.jsx:13`) — one of `idle | greeting | daily_available | completed_today | mic_needed | offline`.
  2. Hub renders Rotjtjbot stage + state chip + state-driven primary CTA (`HomeHubScreen.jsx:18-66`).
  3. Hub renders secondary trio Course / Review / Progress (`HomeHubScreen.jsx:163-165`).
  4. Hub renders TopBar with parent-area entry (`HomeHubScreen.jsx:90`) and settings entry (`HomeHubScreen.jsx:97`).
- **Postconditions:** Child is on `home_hub_<variant>` with all six entry points wired to their `go(...)` targets.

## UC-H02 — Tap Rotjtjbot for Greeting

- **Goal:** Child gets immediate feedback the rotjtjbot is "alive" without committing to a lesson.
- **Trigger:** Child taps the centered Rotjtjbot avatar (`HomeHubScreen.jsx:123` `onRotjtjbotTap`).
- **Preconditions:** UC-H01 active; any home variant except `greeting` (which already shows the greet face).
- **Main Flow:**
  1. Tap calls `onRotjtjbotTap` → `setGreet(true)` and arms an 1800 ms timer (`HomeHubScreen.jsx:69-74`).
  2. Rotjtjbot avatar swaps to `emotion='greet'`, plays a `home-bounce` keyframe, and shows a "Hi!" speech bubble (`HomeHubScreen.jsx:140-144`).
  3. Timer fires → `setGreet(false)` → avatar reverts to the variant-driven emotion.
- **Postconditions:** No navigation; `useLessonStore` untouched; tap is purely affordance.

## UC-H03 — Start Today's Lesson

- **Goal:** Child enters the daily voice activity from the hub primary CTA.
- **Trigger:** Child taps the state-driven primary CTA (`HomeHubScreen.jsx:157`) when its `ctaTarget` is `lesson_ready`.
- **Preconditions:** Home variant is `idle`, `greeting`, or `daily_available` (the three variants whose CTA target is `lesson_ready` per `cfg` block in `HomeHubScreen.jsx:18-46`).
- **Main Flow:**
  1. Child taps "Start Today's Lesson".
  2. `go('lesson_ready')` fires → cross-domain handoff to lesson-session (see cross-domain-edges.json: UC-H03→UC-L01).
  3. Lesson-ready surface renders the "I'm ready!" CTA which begins the voice loop (UC-L01).
- **Postconditions:** Navigation lands on `lesson_ready`; lesson session has not yet started — `useLessonStore.sessionId` still null until UC-L01 fires.

## UC-H04 — Open Course

- **Goal:** Child enters the course tree to browse levels and units.
- **Trigger:** Child taps the "Course" secondary button (`HomeHubScreen.jsx:163`).
- **Preconditions:** UC-H01 active.
- **Main Flow:**
  1. Child taps Course button.
  2. `go('course')` fires → cross-domain handoff to course-browse (see cross-domain-edges.json: UC-H04→UC-C01).
- **Postconditions:** Navigation lands on `course` (Browse Course Tree, UC-C01).

## UC-H05 — Open Review → `review_entry`

- **Goal:** Child enters review mode for vocabulary they have already encountered.
- **Trigger:** Child taps the "Review" secondary button (`HomeHubScreen.jsx:164`).
- **Preconditions:** UC-H01 active. Optional badge count is rendered if `cfg.reviewBadge` is set.
- **Main Flow:**
  1. Child taps Review button.
  2. `go('review_entry')` fires → cross-domain handoff to course-browse (see cross-domain-edges.json: UC-H05→UC-C07).
- **Postconditions:** Navigation lands on `review_entry` (Start Review, UC-C07).

## UC-H06 — Open Today's Progress → `today_progress`

- **Goal:** Child sees what they accomplished today (stars, words learned, streak).
- **Trigger:** Child taps the "Progress" secondary button (`HomeHubScreen.jsx:165`) OR the primary CTA when home variant is `completed_today` (CTA target switches to `today_progress` per `HomeHubScreen.jsx:47`).
- **Preconditions:** UC-H01 active.
- **Main Flow:**
  1. Child taps Progress button (or the "See what you did today" CTA in `completed_today` variant).
  2. `go('today_progress')` fires → cross-domain handoff to progress (see cross-domain-edges.json: UC-H06→UC-P01).
- **Postconditions:** Navigation lands on `today_progress` (Today's Progress, UC-P01).

## UC-H07 — Open Kid Settings → `kid_settings`

- **Goal:** Child opens kid-facing settings (volume, rotjtjbot personality, accessibility toggles).
- **Trigger:** Child taps the gear icon in the top-right CircleBtn (`HomeHubScreen.jsx:97`).
- **Preconditions:** UC-H01 active.
- **Main Flow:**
  1. Child taps the gear icon.
  2. `go('parent_settings')` fires (the prototype routes to a unified settings target — kid-settings sub-surface is presented within the same screen target).
- **Postconditions:** Navigation lands on the kid-settings surface; auth status unchanged. (Kid-settings is a kid-hub-owned surface and does not require parent gate; no cross-domain edge.)

## UC-H08 — Enter Parent Space

- **Goal:** Parent (or supervising adult) crosses the speed-bump into the parent-only surface.
- **Trigger:** User taps the parent-area icon in the top-left CircleBtn (`HomeHubScreen.jsx:90`).
- **Preconditions:** UC-H01 active.
- **Main Flow:**
  1. User taps the parent-area icon.
  2. `go('parent_gate')` fires → cross-domain handoff to parent-gate (see cross-domain-edges.json: UC-H08→UC-PR01).
  3. Parent-gate enforces the speed-bump (UC-PR01); on success the user lands in parent-summary (UC-PR02..PR07 surfaces).
- **Postconditions:** Navigation lands on `parent_gate`. Auth status unchanged; the speed-bump is a UX gate, not a security boundary (KD4).
