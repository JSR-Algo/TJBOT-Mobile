## UC-P01 — View Today's Progress

- **Goal:** Child sees a summary of today's activity (lessons completed, words practiced, time spent) so they can feel a sense of accomplishment.
- **Trigger:** Child navigates to the Progress tab from `home_hub_idle` or any bottom-nav entry point.
- **Preconditions:** Child is authenticated; at least one lesson session has been recorded for today.
- **Main Flow:**
  1. `TodayProgressPage` mounts and dispatches `getTodayProgress()` from `src/services/api/progress.api.js`.
  2. UI renders today's lesson count, word count, and session duration from the response.
  3. Child can tap "Words practiced" card to drill into UC-P02.
- **Postconditions:** Progress data is displayed; no state mutations occur (read-only view).

## UC-P02 — View Words Practiced

- **Goal:** Child reviews the specific vocabulary words practiced in today's sessions, reinforcing retention awareness.
- **Trigger:** Child taps the "Words practiced" drill-down from UC-P01 (`TodayProgressPage`).
- **Preconditions:** UC-P01 is displayed; `getWordsPracticed()` API is reachable.
- **Main Flow:**
  1. `WordsPracticedPage` mounts and calls `getWordsPracticed()` from `src/services/api/progress.api.js`.
  2. UI renders a list of words with their practice status (correct / needs review).
  3. If two or more words are flagged "needs review," a "Practice 2 words" CTA is shown (puml edge: `UC_PRG_WORDS ..> UC_PRG_REVIEW`).
  4. Child taps the CTA to enter UC-P04.
- **Postconditions:** Word list displayed; if CTA tapped, navigates to UC-P04.

## UC-P03 — View Lesson Summary

- **Goal:** Child (and optionally parent) sees a structured recap of the just-completed lesson — score, words covered, time taken.
- **Trigger:** Lesson session ends (`UC_LSN_DONE` event from lesson-session domain); app navigates to `progress_summary`.
- **Preconditions:** A lesson session has just concluded; `getLessonSummary()` API is reachable.
- **Main Flow:**
  1. `LessonSummaryPage` mounts with the completed session ID passed as route param.
  2. Calls `getLessonSummary()` from `src/services/api/progress.api.js` with session ID.
  3. Renders score (e.g. 4/5 words), time elapsed, and list of words covered.
  4. If any words need review, a "Review needed" badge is shown; tapping navigates to UC-P04.
  5. "Continue" CTA advances child to UC-P05 (celebration).
- **Postconditions:** Summary displayed; session is closed. Navigation state points to `progress_celebrate` or `progress_review`.

---

## UC-P04 — View Review Needed

- **Goal:** Child is directed to a focused review run for words that were answered incorrectly, improving retention before the next lesson.
- **Trigger:** Child taps the "Review needed" badge from UC-P03, or the "Practice 2 words" CTA from UC-P02.
- **Preconditions:** Review queue is non-empty (`getReviewQueue()` returns ≥ 1 word); child is authenticated.
- **Main Flow:**
  1. `ReviewNeededPage` mounts and calls `getReviewQueue()` from `src/services/api/progress.api.js`.
  2. UI lists words queued for review with a "Start review" CTA.
  3. Child taps "Start review" → navigates to lesson-session domain (`UC_LSN_START` review run — puml note `[exit] → lesson-session`).
- **Postconditions:** Child enters a review lesson session (UC-L01); progress domain is exited.
- **Alt Flow:**
  1. Review queue becomes empty (all words already mastered) → "Nothing to review" state with back navigation to `progress_today`.

## UC-P05 — View Celebration

- **Goal:** Child receives positive reinforcement (animation, congratulatory message) after completing a lesson, motivating continued engagement.
- **Trigger:** Child taps "Continue" at the end of UC-P03 (`LessonSummaryPage`).
- **Preconditions:** UC-P03 has been displayed for the current session; no further async calls required.
- **Main Flow:**
  1. `CelebrationPage` mounts with session-level achievement data (words mastered count, streak).
  2. Celebration animation plays (lottie or similar).
  3. "Back to home" CTA or auto-advance after 4 s navigates child to `home_hub_idle`.
- **Postconditions:** Child returns to `home_hub_idle`; no state mutations from this screen.
