# Pika Red LCD Face

Single-color matte red robot eye system for TeeBot's 800x480 face screen.

- Preview: `http://localhost:8765/pika-red/preview.html`
- Kiosk: `http://localhost:8765/pika-red/preview.html?kiosk=1`
- One state: `http://localhost:8765/pika-red/preview.html?state=listening&kiosk=1`
- State cycle: `http://localhost:8765/pika-red/preview.html?cycle=1`

The prototype keeps one character identity and changes only geometry, motion, and opacity between emotional states. It is meant as the local animation reference before rebuilding the selected eye system in Rive or LVGL.

The Firefly concept reference is saved as `firefly-matte-red-reference.png`.
