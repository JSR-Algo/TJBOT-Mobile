## UC-F01 — View Network Error

- **Goal:** Child sees a friendly Robot-voiced explanation that the network dropped, with a path back to the lesson when it recovers.
- **Trigger:** Child app detected a network failure during a lesson; navigation routes to `network_error` (`NetworkErrorPage`).
- **Preconditions:** A lesson was active; the network failed.
- **Main Flow:**
  1. `NetworkErrorPage` mounts and renders the worry-emotion Robot + speech bubble "Oops — I lost my signal" (`NetworkErrorScreen.jsx:8-10`).
  2. Page renders the "Try again" primary CTA (`NetworkErrorScreen.jsx:17`).
  3. Child taps "Try again" → navigation transitions to `reconnecting_overlay` (UC-F06) — `NetworkErrorScreen.jsx:17`.
- **Postconditions:** Network recovery sequence is in flight; navigation lands on the reconnect overlay.
- **Alt Flow:**
  1. Child taps "Go home" → returns to `home_hub_idle` (cross-domain — see cross-domain-edges.json) — `NetworkErrorScreen.jsx:18`.

## UC-F02 — View Mic Missing

- **Goal:** Child sees a Robot-voiced explanation that the mic isn't working and a clear "get a grown-up" path.
- **Trigger:** Child app detected mic permission missing or hardware unavailable during a lesson; navigation routes to `mic_missing` (`MicMissingPage`).
- **Preconditions:** A lesson was active; mic became unavailable.
- **Main Flow:**
  1. `MicMissingPage` mounts and renders the sad-emotion Robot + speech bubble "Hmm, I can't hear yet" (`MicMissingScreen.jsx:8-10`).
  2. Child taps "Get a grown-up" → navigation transitions to `audio_recovery` (UC-F03) — `MicMissingScreen.jsx:20`.
- **Postconditions:** Navigation lands on the audio-recovery instructions for a parent to act on.
- **Alt Flow:**
  1. Child taps "Go home" → returns to `home_hub_idle` (`MicMissingScreen.jsx:21`).

## UC-F03 — Audio Permission Recovery

- **Goal:** Parent reads OS-level steps to grant Robot's mic permission so the lesson can resume.
- **Trigger:** UC-F02 routed Child to "Get a grown-up"; Parent picks up the device and lands on `audio_recovery` (`AudioRecoveryPage`).
- **Preconditions:** Parent is now operating the device; mic permission missing.
- **Main Flow:**
  1. `AudioRecoveryPage` renders `ParentScroll title="Microphone access"` (`AudioRecoveryScreen.jsx:18`) with numbered steps.
  2. Parent follows OS-level steps (Settings → Privacy → Microphone → enable for app).
  3. Parent taps "Done / Go home" → returns to `home_hub_idle` (`AudioRecoveryScreen.jsx:49`).
- **Postconditions:** Mic permission granted (real wiring); navigation returns to home hub.

## UC-F05 — Resume Lesson

- **Goal:** Child sees a "welcome back" Robot and one-tap "Keep going" path back into the live lesson.
- **Trigger:** Navigation arrived at `lesson_resume` from UC-F04 voice-failed recovery (or another extend).

- **Main Flow:**

  1. Child taps "Go home" → returns to `home_hub_idle` (`LessonResumeScreen.jsx:29`).

## UC-F06 — View Reconnecting Overlay

- **Goal:** Show a non-blocking overlay while the app retries network/voice connection, then auto-resume the lesson.
- **Trigger:** Network recovery in flight (e.g., from UC-F01's "Try again"); component `ReconnectingOverlay` mounts.
- **Preconditions:** A lesson was active; network/voice recovery in progress.
- **Main Flow:**
  1. `ReconnectingOverlay` mounts and starts a 2.4 s timer (`ReconnectingOverlay.jsx:5-8`).
  2. Overlay renders the worry-emotion Robot + animated dots (`ReconnectingOverlay.jsx:29-37`).
  3. After timeout, navigation transitions to `robot_listening` (cross-domain handoff to lesson-session — see cross-domain-edges.json: UC-F06→UC-L04).
- **Postconditions:** Lesson resumed at the listening state; overlay dismissed.
- **Alt Flow:**
  1. Child / Parent taps "Stop and go home" → returns to `home_hub_idle` (`ReconnectingOverlay.jsx:39`).

## UC-F07 — Safety Redirect

- **Goal:** When the lesson safety filter trips (or a child taps a safety affordance), Robot offers a soft pause path; Parent can intervene via parent gate.
- **Trigger:** Safety filter hit during a lesson, or child invoked the safety affordance from kid-settings; navigation routes to `safety_redirect` (`SafetyRedirectPage`).
- **Preconditions:** Either a lesson was active and safety tripped, OR a child-initiated path landed here.
- **Main Flow:**
  1. `SafetyRedirectPage` mounts and renders the gentle Robot + speech bubble "Let's take a tiny pause" (`SafetyRedirectScreen.jsx:8-10`).
  2. Child taps "Take a break" → returns to `home_hub_idle` (`SafetyRedirectScreen.jsx:19`).
- **Postconditions:** Lesson is paused; child returned to home hub.
- **Alt Flow:**
  1. Parent taps "I'm a grown-up" → routes to `parent_gate` (cross-domain — see cross-domain-edges.json: UC-F07→UC-PR01) — `SafetyRedirectScreen.jsx:20`.

## UC-F08 — View Generic App Error

- **Goal:** When an unexpected exception is caught (ErrorBoundary or async wrapper), surface a friendly Robot-voiced fallback with retry-in-place + go-home.
- **Trigger:** Top-level `ErrorBoundary` or async wrapper caught an exception; component `AppErrorPage` mounts.
- **Preconditions:** An unhandled exception was raised.
- **Main Flow:**
  1. `AppErrorPage` mounts and renders the worry-emotion Robot illustration + a friendly headline (`AppErrorScreen.jsx:9-`).
  2. Page renders two CTAs (`AppErrorScreen.jsx:25-31`): "Try again" → calls `reset()` (re-mount the failed subtree); "Go home" → calls `go('home_hub_idle')`.
  3. Caller decides which path to take.
- **Postconditions:** Either the failed subtree retried, OR navigation returned to the home hub.
