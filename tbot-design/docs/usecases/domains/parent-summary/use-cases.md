## UC-PR02 — View Parent Summary

- **Goal:** Parent sees a consolidated dashboard of their child's recent learning activity, providing a one-stop overview before drilling into details.
- **Trigger:** Parent completes parent-gate (UC-PR01) and lands on `parent_summary`; or taps "Parent summary" from any surface that passes the gate.
- **Preconditions:** Passed parent-gate (UC-PR01) within current session (KD4 — speed-bump, not RBAC). `getParentSummary()` API is reachable.
- **Main Flow:**
  1. `ParentSummaryPage` mounts and calls `getParentSummary()` from `src/services/api/parent.api.js`.
  2. UI renders today's stats card, 30-day streak indicator, and quick-links to UC-PR03, UC-PR04, UC-PR05.
  3. Settings icon in header links to UC-PR06.
  4. Parent can tap any card to drill into the respective sub-UC.
- **Postconditions:** Summary displayed; no state mutations. Navigation state is `parent_summary`.

## UC-PR03 — View Practiced Today

- **Goal:** Parent sees the specific words and lessons their child practiced today, giving actionable visibility into daily learning.
- **Trigger:** Parent taps the "Today" card from UC-PR02 (`ParentSummaryPage`).
- **Preconditions:** Passed parent-gate (UC-PR01) within current session. `getParentToday()` API is reachable.
- **Main Flow:**
  1. `ParentTodayPage` mounts and calls `getParentToday()` from `src/services/api/parent.api.js`.
  2. UI renders list of lessons completed today, words practiced, and time on task.
  3. Back navigation returns to UC-PR02 (`parent_summary`).
- **Postconditions:** Today's data displayed; no state mutations.

## UC-PR05 — View Safety & Privacy

- **Goal:** Parent reviews the safety and privacy settings governing their child's robot interactions, and understands what data is collected.
- **Trigger:** Parent taps "Safety & Privacy" from UC-PR02 (`ParentSummaryPage`).
- **Preconditions:** Passed parent-gate (UC-PR01) within current session. `getSafetyConfig()` API is reachable.
- **Main Flow:**
  1. `ParentSafetyPage` mounts and calls `getSafetyConfig()` from `src/services/api/parent.api.js`.
  2. UI renders current safety filter status, data-retention summary, and COPPA notice.
  3. Parent can toggle safety settings which call `updateSafetyConfig()`.
  4. Successful update shows a confirmation toast; a safety log entry is emitted (cross-domain edge → `fb_safety`).
  5. Back navigation returns to UC-PR02.
- **Postconditions:** Safety config displayed and optionally updated; change is persisted server-side.

## UC-PR06 — Configure Parent Settings

- **Goal:** Parent adjusts account-level settings (notification preferences, language, linked robot) and can navigate to robot management.
- **Trigger:** Parent taps the settings icon in the `ParentSummaryPage` header (puml note: `[header]` from UC-PR02).
- **Preconditions:** Passed parent-gate (UC-PR01) within current session. `getSettings()` API is reachable.
- **Main Flow:**
  1. `ParentSettingsPage` mounts and calls `getSettings()` from `src/services/api/parent.api.js`.
  2. UI renders notification toggle, language picker, and "Manage Robot" CTA.
  3. Parent edits settings; changes are saved via `updateSettings()` on blur/toggle.
  4. "Manage Robot" CTA navigates to robot-mgmt domain (`UC_RM_VIEW` — puml exit note).
  5. Back navigation returns to UC-PR02.
- **Postconditions:** Settings updated if changed; navigation may exit to robot-mgmt domain.

## UC-PR07 — Open Help & FAQ

- **Goal:** Parent accesses help content and frequently asked questions to self-serve common support needs.
- **Trigger:** Parent taps "Help & FAQ" from any parent-summary surface (bottom link or overflow menu).
- **Preconditions:** Passed parent-gate (UC-PR01) within current session.
- **Main Flow:**
  1. `ParentHelpPage` mounts and renders static FAQ content (no API call required — content is bundled or loaded from a CDN).
  2. FAQ items are expandable accordion entries.
  3. "Contact support" link opens the device email client with a pre-populated subject.
  4. Back navigation returns to UC-PR02.
- **Postconditions:** Help content displayed; no state mutations.
